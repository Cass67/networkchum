Not covered by the matrix

  • Container runtimes — docker and podman do not start without nested virtualisation, so only CLI presence is checked.
  • KVM/TAP VM labs inside the guest.
  • macOS / Homebrew.
  • Immutable Fedora (CoreOS, rpm-ostree) — the tested Fedora image is mutable Cloud Base on btrfs; there is no rpm-ostree branch in the installer.

3 · Installer fixed against real distros70dd12d · 07e174a · 8aa4fcb · a51abc8 · f0cf6f0
Six bugs, all found only by running the installer on the platforms we claim to support:
RHEL family   moby-engine/docker-cli do not exist on Rocky/Alma
              → prefer docker-ce, fall back to moby-engine, then podman-docker shim
RHEL family   qemu-system-x86_64 ships in qemu-kvm-core
              → install it alongside qemu-kvm
RHEL family   the podman-docker shim has no docker.service and no docker group
              → systemctl enable / usermod are now conditional
dnf           QEMU probe used `dnf info` (installed packages only) and always
              picked qemu-kvm → now `dnf list --available`
Arch          `pacman -S` prompted without --noconfirm and aborted the
              non-interactive install
Arch/openSUSE a docker daemon that fails to start aborted the whole install
              under `set -e` → now non-fatal
4 · openSUSE / SLES support70dd12d
New zypper branch (qemu-x86, qemu-tools, podman/docker), plus --package-manager=zypper and docs.

Open items / risks

  • Tag drift (resolved 2026-11-03): v0.1.1 cut at 030d398; v0.1.0 remains on 6adff4c as history.
  • Immutable Fedora (CoreOS) is not supported — rpm-ostree, no installer branch.
  • npm resolver bug: npm 10.9.8 crashes (Cannot read properties of null (reading 'edgesOut')) on plain npm install in this workspace; npm ci works and the deploy flow uses it.
  • Data dir is repo-local (apps/api/data, gitignored) — a git clean -xdf on the box would wipe labs and the token.
  • systemd warns KillMode=none is deprecated; intentional, so labs survive restarts.
  • Harness flakiness: the Fedora VM occasionally dies during the final steps; -no-reboot -no-shutdown mostly fixes it, but it needed several attempts.
  • Pre-commit hooks are not wired into any npm script.
