Notes

Style is the out-of-the-box default: classic Visio / Cisco stencil language — shaded gradient fills, thin dark navy outlines (#0f3f66), isometric depth on the switch, brick-wall firewall, rack-style server, monitor-with-stand client. No glow, no dark-theme dependency: it sits on light or dark canvas.

Shapes are drawn on a 64×64 grid, single-weight outlines so they redraw cleanly at 24×24 in apps/web/src/icons/deviceRoleIcons.tsx. Gradients can live in one shared <defs> block (as in this page) or be inlined per glyph.

Palette: router blue #1a6bb0→#7dcdf7, switch iso faces #1c5f9c / #b0d8f0, cloud #cfe8fa→#fff, server gray #b8c6d4→#f0f4f8, client #9db8cf→#dce9f4, firewall brick #a5432f→#d2694f with cream mortar.

State/selection: dashed outline box for selection, green/gray status chip for running/stopped — consistent with the design doc's rule that state is expressed around the glyph, not by changing the glyph.

Neon set from the previous mockup (2026-10-20-neon-network-icons.html) is kept as an optional theme.
