Notes

Shapes follow classic network-diagram-tool language: router = circle with crossed arrows (Cisco-style), switch = box with opposing arrows, firewall = brick wall, cloud, server chassis, CRT monitor for client. Strokes are single-weight so they redraw cleanly at 16px on the existing 24×24 grid in apps/web/src/icons/deviceRoleIcons.tsx.

Neon treatment is a per-role stroke color + drop-shadow glow over a dark fill, so it can live in CSS (currentColor-friendly) rather than baked into the SVG. State/selection can be expressed by shifting stroke color or glow intensity per the design doc.

Palette: cyan #00e5ff (router), magenta #ff2fd6 (switch), amber #ffb347 (firewall), violet #b46bff (cloud), green #3fff9c (host), coral #ff5e5e (client).
