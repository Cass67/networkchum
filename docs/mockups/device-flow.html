NetworkChum — Device & Image Flow Mockups

Four proposed screens, using the existing theme.css palette. Not wired to the API — pure visual mockups.

The catalog becomes the hub: grouped by vendor, search + filter chips, and unbound templates shown in a "needs image" state whose CTA opens the upload dialog pre-targeted at that template. No more "source: image-bound" jargon.
