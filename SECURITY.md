# Security Model

## Threat model

NetworkChum is a single-host lab workbench intended to run on your own
machine or a trusted LAN host. It executes VMs and containers and exposes
serial consoles, so the API is deliberately token-gated.

## API authentication

- Every API route except `GET /health` requires the `x-networkchum-token`
  header (or `Authorization: Bearer <token>`). Mismatches get `401`.
- The token is a 256-bit random value generated by `./start.sh serve` the first
  time it runs, stored in the data directory as `api-token` with mode `0600`,
  and passed to the API process via the `NETWORKCHUM_API_TOKEN` environment
  variable. Comparisons are timing-safe (`crypto.timingSafeEqual`).
- The web UI stores the token in the browser's `localStorage` and attaches it
  to every request. A token entered in one browser is not shared with others;
  each browser authenticates separately.
- `GET /health` is intentionally open (liveness probes); it returns capability
  metadata only and no user data.

## Token rotation

- Server side: delete `<data-dir>/api-token` and restart the service — a fresh
  token is generated and every outstanding browser token stops working.
- Browser side: use the **API Token** button in the canvas controls, or run
  `localStorage.removeItem("networkchum-api-token")` and reload — the token
  dialog re-appears.
- Retrieve the current token with `./start.sh doctor` on the server.

## Exposure

- `localhost` mode (default) binds the UI and API to loopback only.
- `lan` mode binds to `0.0.0.0` so workstations on your LAN can reach the UI
  and API. In this mode the token is the only thing between a LAN peer and the
  API — the API can create/delete labs, power nodes, and execute container
  commands — so treat the token as a secret and keep the host off untrusted
  networks.
- The native console bridge (`127.0.0.1:4010`) is localhost-only and spawns
  terminal windows on the machine running it.
- There is no multi-user model: everyone shares the same token and the same
  labs.

## Reporting

This is a personal/homelab project; there is no security bounty program. Open
a GitHub issue for anything you find.
